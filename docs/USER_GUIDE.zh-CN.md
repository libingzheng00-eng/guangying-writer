# 光影写手中文使用说明书

适用于 **1.3.0-alpha.18.17**。光影写手把剧本正文、场景卡片、创作素材和改稿记录放在同一个工程中；交稿时，再选择适合阅读或交换的导出格式。本文示例均为虚构。

第一次使用，建议先完成这条流程：**新建剧本 → 写一场戏 → 保存 `.zhsp` → 预览 → 导出 PDF**。开始重要修改前，可另存一份工程，并在“改稿”中保存一个命名版本。

## 1. 下载、安装与升级

请从 [GitHub Releases](https://github.com/libingzheng00-eng/guangying-writer/releases) 查看对应版本的附件与说明。源码 ZIP 不是桌面应用；某个平台的附件是否已经提供，以该版本下载页为准。

| 平台 | 当前适用范围 | 安装与签名边界 |
| --- | --- | --- |
| macOS | macOS 13 或更新版本，Apple Silicon（arm64） | 下载对应的 DMG 或应用 ZIP，打开后把应用放到自己的应用目录。当前使用 ad-hoc 签名，未经 Apple 公证，不能据此认为其他电脑一定可直接打开。 |
| Windows | Windows 10 或更新版本，x64 | 使用免安装 ZIP，先完整解压，再运行其中的程序；保留同目录的配套文件，不要只搬走 `.exe`。当前未作 Windows 代码签名。 |

本手册不承诺 Intel Mac、Windows 32 位或原生 ARM64 包的可用性。若系统提示来源或签名问题，先核对下载来源、系统和附件架构；不要为安装而关闭整台电脑的安全保护。

升级前先在旧版中保存工程并正常退出。保留原工程与旧版应用，用工程副本试用新版。发布了新版本不会自动替换你正在使用的应用。

**新旧版本混用：**

- 新版可以打开所有旧工程。
- 从 alpha.18.17 起，用本版打开**更新版本**保存的工程时，会先弹出提示；选择「打开并保留新版内容」后，本版看不懂的内容会原样保留，保存时一并写回，不会丢失。
- alpha.18.16 及更早的版本没有这种保护：用它们打开并重新保存新版工程，会丢失它们不认识的内容（alpha.18.15 及更早会丢命名版本、暂存、批注和交稿忽略记录；alpha.18.16 会丢人物线信息）。如果一定要用旧版，请先复制一份工程。

## 2. 启动页与最近项目

启动页提供“新建剧本”“打开工程…”和“最近项目”。存在当前写作或可恢复内容时，会显示“继续写作”；旁边的文字区分继续当前写作还是上次写作。

- **新建剧本：**从空白开始。有未保存修改时，先处理提示再切换。
- **打开工程…：**选择本地文件。工作界面中也可用“文件 ▾ → 打开…”。
- **最近项目：**按名称或路径搜索，用“置顶”保留常用项目；“移除记录”只清理列表，不删除工程文件。
- **重新定位…：**文件移动、改名或需要重新授权时，重新选择正确文件。列表中的旧路径不是文件仍然存在的保证。
- **启动时：**可选“显示启动页”或“继续上次写作”。随时可通过“文件 ▾ → 启动页 / 最近项目”返回。

软件会尝试记住本机的写作位置。它只是阅读便利，不会写成正文，也不替代保存。

## 3. 保存、另存为与恢复

### 工程文件与交稿文件

**`.zhsp` 是继续创作的工程文件。**点击“保存”，第一次保存时选择文件名和位置；“文件 ▾ → 另存为…”创建另一份工程，并把后续保存关联到新位置。名称旁的圆点表示仍有未保存修改。

PDF、FDX、TXT、Markdown 和 HTML 是导出文件，不能完整代替 `.zhsp` 备份。导出成功也不代表工程已经保存。

### 自动恢复点

底部状态栏会显示“恢复点待更新”“恢复点尚未建立”、恢复时间或“恢复点失败”。自动恢复用于意外关闭后的继续写作，只保留一份最新快照，**不是逐稿历史，也不等于已保存到磁盘的 `.zhsp`**。

恢复出的内容会保守地标为未保存。先核对正文和素材，再点击“保存”或“另存为…”。若提示恢复失败或保存失败，先保存一份到可写的位置，不要因为界面仍能编辑就忽略提示。

关闭、新建或打开另一份稿件时，软件会检查未保存内容与尚未确认的草稿。想继续处理当前稿件，应选择保留当前写作的选项。取消文件选择或打开失败，不应当作已经切换工程。

### 上一版备份与长期备份

覆盖已有工程时，软件会在同一目录保留一个名为 `<工程文件名>.guangying-backup` 的上一版备份。它只有一份，会随后续保存更新，不是无限历史。

需要尝试恢复该备份时，先保留原工程，再把备份复制成一个新的 `.zhsp` 文件名后打开。重要阶段仍建议“另存为…”独立文件，并另做外部备份；例如“渡口_第二稿.zhsp”“渡口_交稿前.zhsp”。

### 导入其他格式

“打开…”可以读取 `.zhsp`、FDX，以及按文本识别的 TXT、Markdown 文件。独立稿件建议从这里打开；从其他格式打开后，第一次保存会要求选择新的 `.zhsp`，不会把导入源覆盖成工程格式。文本识别可能把短句认作人物名，导入后应检查段落类型；Markdown 导入也不是完整的 Markdown 排版还原。

“文件 ▾ → 导入文本 / FDX…”用于向现有剧本加入内容。选好文件后，软件会显示识别到的元素数，并给出三个选项：**追加到剧本末尾**、**替换整个剧本**、**不导入**。按 Esc 或点击窗口外，都等于“不导入”。如果当前剧本有未保存的修改，提示里会写明，选“替换整个剧本”会放弃这些修改。

## 4. 写作：段落类型与输入节奏

顶部工作视图有“写作”“故事板”“自由板”“预览”“统计”。窄窗口下可能收为“工作视图”下拉框。

在“写作”中，每段有明确类型。把光标放入段落，再用顶部类型下拉框选择：

| 类型 | 适合写什么 |
| --- | --- |
| 幕 / 分集 | “第一幕”“第三集”等结构标题 |
| 场次标题 | “内景 渡口候船室 日”等场景标题 |
| 动作 | 可见动作、环境与叙述 |
| 人物 | 说话者姓名 |
| 括号提示 | 对白前的简短语气或动作提示 |
| 对白 | 人物说的话 |
| 转场、镜头 | “切至”“特写”等表达 |
| 一般性文本 | 不需要上述特定格式的正文 |
| 备忘 | 写在正文结构中的创作笔记；导出规则与批注不同 |

光标在正文时，**Tab** 按“动作 → 人物 → 括号提示 → 对白 → 转场 → 镜头 → 场次标题 → 一般性文本 → 备忘”循环；**Shift+Tab** 反向循环。它只改变当前段落类型，不另起一段，也不跳到工具栏。需要“幕 / 分集”时使用类型下拉框。

**Enter** 通常新建下一段：场次标题后是动作，动作后仍是动作，人物后是对白，对白后是人物。光标在段中时，尾部文字移到新段。**Shift+Enter** 在同一段内换行。

从空段开始输入时，快捷输入可能推荐人物、镜头、转场或场次前缀。例如输入“特”后选择“特写 · 镜头”。有候选时，**第一次 Enter 确认候选并留在本段，第二次 Enter 才切段**；也可点击候选或用右箭头确认，Esc 收起候选。已有正文、粘贴文字和中文输入法正在组词时，不应套用“每次 Enter 都接受软件候选”的理解。

选中文字后可使用 **B、I、U** 加粗、斜体、下划线。顶部进度栏可以收起：鼠标移到进度栏上，点栏底中间的小把手；收起后点写作区顶部的把手再展开。“＋场”在当前场景之后插入新场景。工具栏的双列图标可把附近的对白组设为双列，并创建另一侧对白；先在“设置 → 常规”启用双列对白，再在对白组中操作。

“多选段落”进入段落选择模式；点击正文或复选框选择，Shift 点击可连续选择。用“完成多选”返回编辑。若这些段落可能以后还要用，先按第 7 节暂存，不要直接“删除所选”。

“⊘”为当前元素添加或恢复省略标记。**省略不等于删除，也不保证所有导出格式都排除该文字。**不应发送的正文请先明确移出，并核对最终导出文件。

### 查找、替换与撤销

点击“查找”（⌘/Ctrl+F）搜索正文，也能找到备忘；可勾选“区分大小写”。Enter 找下一处，Shift+Enter 找上一处，Esc 关闭。

需要替换时，点面板上的“替换”展开替换栏，填写新文字（留空表示删除），然后点“替换”只改当前这一处（在替换框里按 Enter 也可以），或点“全部替换”。原有的粗体、斜体、下划线会保留。每次替换，包括一次全部替换，都只算一步撤销。改人物名时，建议同时到“统计”里核对人物列表。

“↶ / ↷”撤销、重做正文、场景、卡片等已提交修改。保存不会清空本次会话的撤销记录；新建、打开另一份工程会重置记录，退出后的工程文件也不携带撤销历史。尚未确认的输入框草稿使用自己的文字编辑历史。

## 5. 场景、故事板与正文顺序

一场戏由场次标题及其后的正文组成，直到下一个场次标题。侧栏的“导航”“大纲”“属性”与故事板展示的是同一份剧本。

侧栏可定位场景；大纲可拖动场号，将整场放到目标场景之前或之后。场号会随正文顺序更新。卡片的标题、梗概是辅助信息，修改它们不会自动重写正文中的场次标题。

### 故事板的两种排列

“故事板”中的“排列”提供：

- **按幕分组：**用场号拖动场景归幕，也可多选后移动。Shift 连选，⌘/Ctrl 多选。“未归幕”表示没有幕归属；移回未归幕只解除归属，保留正文位置。归入正式幕则会按落点移动整场。
- **正文顺序：**按实际阅读顺序列出场景。用上移、下移按钮调整整场位置，同时查看标题、梗概和场景信息。

删除幕会保留场景；删除场景会影响真正的正文，并非仅隐藏一张卡片。删除前可先把整场暂存，误操作后及时撤销。

### 场景简介与修改状态

每场戏有一段“简介”，在大纲、属性、故事板和自由板里是同一份，改一处其他地方同步。简介可以加粗、斜体、加下划线：选中文字后点工具栏的 B / I / U，或按 ⌘/Ctrl+B / I / U。粘贴进来的内容只保留文字。

地点和时间已经写在场次标题里，所以卡片上不再另外填写。“修改状态”可选“未标记”“待修改”“修改中”“已确认”，设置后会在卡片标题旁显示一个小标记。

在故事板里，卡片的主体就是简介，场次标题显示在卡片底部。勾选一张或多张卡片后，顶栏会出现颜色和修改状态，可以一次改好所选场景；“正文顺序”排列中，简介写完按 Enter 或点别处提交，Esc 放弃，Shift+Enter 换行。这些信息随工程保存，不会自动写进正式剧本。

**正文排序与板面摆放是两件事：**在大纲或故事板调整整场顺序，会改变剧本的阅读顺序；在自由板拖动卡片，只改变板面位置。

## 6. 自由板与写作素材

“自由板”是一块自由白板，分“总览”“场景板”“灵感板”。“＋ 新增”可创建“场景卡”“灵感卡”“声音卡”“图片卡”。场景卡对应真实场景；声音卡用于记录声音、环境、音乐或节奏的文字设想，不是音频播放器。

点击选中卡片，拖动安排位置；Shift 多选、⌘/Ctrl 增减选择，空白处拖动框选。按住空格拖动或用鼠标中键平移，顶栏右侧的“− 100% ＋”调整缩放，也可以直接点百分比，输入 40–200 之间的数字后按回车（Esc 放弃）；触控板捏合与鼠标滚轮按滑动幅度细微缩放。拖动卡片时默认按网格磁吸，卡片会落在网格线上排得整齐；按住 Alt 可临时不吸，“视图”菜单里可以关掉磁吸、隐藏网格或重置视图。卡片颜色会铺满整张卡片。

素材卡标题普通点击仍可选择、拖动；双击标题，或把焦点移到标题后按 F2 / Enter，进入标题编辑。Enter 或失焦提交，Esc 取消。场景卡可双击定位正文。素材卡选中后的“关联到场景”用于记录所属场景，不会自动重排正文或卡片。

选中卡片后，顶栏会显示颜色、修改状态（场景卡）或“关联到场景”（素材卡），不再弹出浮动窗口。卡片里的文字同样可以加粗、斜体、下划线。

**连线：**把鼠标移到卡片右上角，会出现一个蓝色圆点，按住它拖到另一张卡片上松开，就连好了；松在空白处或按 Esc 取消。也可以先选中两张卡片，再点顶栏的“连线”或按 L。选中连线后可删除该线；双击线上的说明，或选中后按 F2 / Enter，编辑关系说明。删除线不删除卡片。

删除场景卡可能删除整场正文，确认框会说明影响；删除普通素材卡只处理相应素材。操作后可撤销。

### 把参考图放在正文旁

在“写作”视图，把本地图片直接拖到画布，会生成图片卡；它不变成正文段落。拖动卡片把参考图放到相关场景旁，可填写标题和备注。在正文两侧的空白处点右键，可以新建声音卡、新建图片卡，或隐藏 / 显示所有卡片；新卡出现在点右键的位置。窗口变窄或打开侧栏时，卡片会自动收进可见范围，不会出现横向滚动条。

写作与自由板使用同一套素材，但**板面位置与写作画布位置分开保存**。在自由板把图片移到右上角，不会把写作画布及创作版 PDF 中的图片一起移走。要改变创作版 PDF 中的图文位置，应在写作画布调整。

写作区右键菜单里的“隐藏所有卡片”只帮助专注编辑；创作版 PDF 导出时仍会包含全部卡片。请勿把这个显示开关当作交稿过滤器。

## 7. 改稿工作台：版本、批注、暂存

先在正文放好光标或选好文字，再点击顶部“改稿”。工作台记住**打开时的位置和选择**，用于批注与插入取回。需要换目标时，关闭工作台、重新选择，再打开；取回前核对界面上的“插入到……后”。

工作台的已确认操作进入工程，可撤销；仍需点击“保存”才能写入 `.zhsp`。关闭、切换功能或更换编辑对象时，未确认草稿会要求处理；“取消操作”保留草稿，“放弃草稿并继续”才放弃。各输入区的取消按钮只放弃对应草稿。

### 版本：保留修改前的正文

1. 打开“版本”，填写如“第二稿·调整开场前”，点击“保存当前版本”。
2. 从列表选一个旧版本，查看“所选旧版本 → 当前正文”的比较；可以搜索、重命名或删除版本。
3. 展开差异场次，查看新增、删除、修改或可能移动的提示，以及旧版与当前场景信息。比较以场次为主，不是逐字修订痕迹。
4. 勾选需要的旧段落，或用“勾选此场旧段”，再点击“取回所选 N 段”。

取回会在打开时的目标段落之后插入**新副本**，保留当前正文，不整稿覆盖。只取回半边双列等不完整结构时，可能转为普通段落并提示，请在插入后检查格式。

命名版本只保存正文与场景信息，不保存图片、素材布局、设置、标题页或其他改稿记录。需要完整项目阶段备份，应“另存为…”工程文件。

### 批注：记录问题与明确决定

“批注位置”可选“选中文字”“当前段”“当前场景”。精确文字批注目前支持单段选区；跨段选择不会自动猜测锚点。请回正文选择单段文字，或明确改选当前段、当前场景。

填写“新批注”后点击“添加批注”。编辑已有批注时，可选择“待处理”“已处理”“不采用”；不采用必须写明原因。“创作决定（确认后记录）”用于写下确定采用的处理办法，例如“保留沉默，不增加解释对白”，最后点击“确认批注与决定”。它不会替你修改正文。

原文改变后，批注会提示原文已改变；仍存在的段落可以定位，但精确文字范围需重新挂接。原文删除后，批注仍保留原摘录和处理记录，不会自动挂到别处的同一句话。要迁移它，先选好新的正文位置，再打开工作台，明确选择范围并“重新挂接”。

可按文字、原文或决定搜索，并按处理状态筛选。编辑一条批注期间，请先确认或取消该条编辑，再搜索、筛选。批注与正文中的“备忘”是不同的数据。

### 暂存：保留删减稿和备选写法

1. 在正文把光标放入目标段，或用“多选段落”选择若干段，再打开“改稿 → 暂存”。
2. “暂存范围”选择“打开时的当前段”“打开时多选的段落”或“打开时的整场”，填写暂存名称及可选备注。
3. “复制存入”只保留副本；“存入并移出正文”会先确认，然后把保存与移出作为一次操作完成。
4. 以后选中条目，核对来源和原文，再点击“恢复暂存副本”。副本插入到目标段落之后，暂存条目仍保留。

多选按正文顺序保存；不连续的段落恢复时会连续插入。暂存不保存素材卡或自由板布局。普通退格、Delete 或“删除所选”不会自动进入暂存，想留下删稿必须明确执行暂存操作。

### 容量与撤销

工作台底部显示容量：最多 **20 个版本、100 条暂存，两类合计 2 MiB**；批注最多 **500 条、合计 1 MiB**。达到限制时需主动整理，软件不会悄悄删除旧记录。删除版本、暂存或批注均会确认，并可在本次会话内撤销。

“撤销本次操作”“重做”处理本次打开工作台后的操作。若有未确认草稿，先确认或取消草稿，再撤销已提交操作；需要撤销更早的正文修改时，关闭工作台后操作。

## 8. 交稿检查与忽略管理

打开“改稿 → 交稿检查”。当前检查三类问题：**没有有效正文的空场、疑似不一致的人物名、待处理批注**。它帮助发现值得核对的地方，不评价故事质量，也不自动统一姓名或改正文。

使用“定位正文”查看位置，或“查看批注”处理对应记录。确认是有意安排后可“忽略此项”；勾选“显示已忽略”查看仍存在的问题，再用“恢复提醒”取消忽略。相关内容改变后，问题可能重新提醒。

已经消失的问题不会继续列在当前扫描结果中，但旧忽略记录可能仍在工程里。“恢复全部提醒（N条记录）”可在确认后清空全部忽略记录，包括这些历史记录；正文不变，可以撤销。忽略记录最多 1000 条，接近上限时用此入口整理。

## 8A. 人物线：沿正文阅读一个人物

点击顶栏“人物线”，从人物列表选择一个名字。正文人物栏会提供初始名单；没有台词的人物也可以点击“登记人物”手动加入。这里是只读阅读，改类型、插场和双列等正文操作应先定位回“写作”。

### 名称、别名与同名人物

“登记此人物”或“管理人物与别名”中填写规范名、每行一个的精确别名，以及选填的同名说明。登记名称不会自动替换正文；修改规范名后，旧名保留为别名。需要修改正文的人物段落，可使用统计页原有的精确改名操作。

软件不会把相似名字合并。同一个名字对应多个人物时，会保留“同名待确认”，请查看原文后逐处指定发言归属。“阿明（青年）”和“阿明（老年）”保留身份差异；V.O.、O.S.、电话等表演后缀单独说明，群体名字不会自动拆开。

### 发言、出场与提及分别核对

人物栏证明有一条发言记录，**不证明人物实际在场**。动作、对白中的名字命中也可能是转述、回忆、否定或假设。展开“本场证据”查看摘录与识别依据，再用“确认 / 纠正”明确实际出场、仅提及、暂不确定或与此人物无关。

没有被自动发现的沉默出场，可勾选“显示所有场景”，找到相应场景后“标记此场人物”。这些分类和理由都是作者判断，软件不自动分析人物心理或补写剧情。

### 连续阅读、搜索与回到正文

场景按当前正文顺序排列；“故事时间”只显示作者已经填写的文字。“完整场景”保留动作与其他人物；“台词聚焦”收起其他上下文，保留括号提示和双列伙伴。很长的场景会分段组阅读。

在人物线按 ⌘/Ctrl+F 搜索相关场景原文，Enter / Shift+Enter 切换命中，Esc 清空搜索。点击“定位命中原文”或证据旁的定位按钮，返回写作中的原始位置；再次点击“人物线”可继续先前阅读。阅读书签只保存在本机，不影响正文或撤销历史。

如果证据原文已改动或被删除，旧摘录与说明会保留并提示核对，不会自动挂到另一处同名文字。撤销删除可以恢复原位置；从版本或暂存取回的是新副本，不会冒充原位置。

### 人物笔记与创作记录

按需添加“人物笔记”“关系变化”或“知道的信息”。它们与改稿工作台共用同一条普通批注，修改会互相同步，随 `.zhsp` 保存。默认状态是“已记录”；勾选“需要后续处理”才会进入交稿检查。这些记录不会自动写进正文或正式导出。

移除人物登记会一并移除它的身份纠正和关联，但普通批注文字仍保留，可在“改稿”查看。不要把移除登记当作删除正文人物；操作可以撤销。分享完整工程时，也会分享这些内部记录。

## 9. 标题页、版式与修订颜色

点击左上方工程名称，或“文件 ▾ → 标题页…”，填写剧名、副标题、编剧、改编自、稿别 / 版本、日期、联系方式和备注。“打印时输出标题页”控制是否启用标题页；正式交稿前在预览中核对。

“设置”包含“版式”“元素缩进”“修订”“外观”“常规”。版式中可调整字体、字号、行距、纸张、页边距、场号、页码及续说提示；元素缩进按全角字符单位设置。修改字号和缩进会影响排版，请重新预览。

“修订”中的“启用修订模式”与稿别颜色，用于给段落标记修订稿别。**标题页的稿别文字、修订颜色、改稿中的命名版本分别有不同用途**：只有命名版本保存可比较的正文快照。

“外观”可切换日间、夜间和写作字体颜色，属于本机显示偏好。默认字体色随主题变化：日间黑色，夜间暖白（#ffe9c4）；A4 纯文本 PDF 使用纸面深色文字，创作版 PDF 保留写作画布的显示效果。

“常规”包含双列对白、对白智能引号和“打印「备忘」元素”。备忘在各导出格式中的处理见下一节。设置与标题页的有效修改会直接进入工程或本机偏好，“完成”只是关闭窗口，不是统一的提交或取消按钮。

### 拍摄稿：锁定场号和页码

剧本进入拍摄阶段后，剧组的通告、分镜都按场号和页码对应，改稿不能让编号乱跳。

- **锁定场号：**“文件 ▾ → 锁定场号（拍摄稿）”。锁定后原有场号不再变：在第 5 场后面新插入的场编成 5A、5B；插在第 1 场前面的编成 A1、B1；删掉的场号不再补位。需要先在设置里打开自动场号。
- **锁定页码：**“文件 ▾ → 锁定页码（拍摄稿）”。锁定后每页从原来那一段起头：某页内容变长，多出来的编成 12A、12B 页；变短的页留空，不把后面的内容拉上来；整页内容删掉后，前一页的页码显示成 12-13。预览和 A4 纯文本 PDF 的页眉都用锁定后的页码。
- 状态栏会显示“场号已锁定”“页码已锁定”。在同一个菜单里可以解除；解除后会重新连续编号 / 分页，软件会先确认。锁定和解除都可以撤销。
- 导出 FDX 时，场号按锁定后的编号输出。

### 备选台词

一句对白想多写几个版本比较时，把光标放在这句对白上，页面右侧会出现“备选”小工具条：

- **＋** 把这句复制成一个新版本并切过去，原来的版本保留，直接在新版本上改；
- **‹ ›** 在各个版本之间切换，中间显示“第几版 / 共几版”；
- **✕** 删掉当前这个版本。

有多个版本的对白，左边页边会显示“⇄ 版本数”。预览、PDF、FDX 和其他导出都只用当前选中的那一版。每次新建、切换、删除都可以撤销。

## 10. 预览与全部导出方式

本文统一使用窗口内的“**文件 ▾**”菜单名称。系统菜单部分名称较短，且不包含全部入口。

| 出口 | 适合用途 | 内容与边界 |
| --- | --- | --- |
| 导出创作版 PDF（原位卡片）… | 自己或团队阅读带参考图、声音设计的创作稿 | 保留写作画布中的正文、图片、声音卡及相对位置；不是自由板截图，不把素材统一追加到文末。 |
| 导出 A4 纯文本 PDF… | 标准纸面阅读、打印和交稿 | 独立的 A4 剧本排版，不含素材卡；当前排除备忘与标记省略的正文元素。 |
| 导出 Final Draft (FDX)… | 用 Final Draft 打开、或交给用 Final Draft 的剧组 | 按 Final Draft 自己的文件结构输出：段落类型、粗体/斜体/下划线、双列对白、场号、场景卡的标题/梗概/颜色、标题页，以及按“元素缩进”换算的版式；中文用 Final Draft 自带的「Sans Mono CJK Final Draft」字体。不含素材卡、备忘和改稿库。为避免 Final Draft 11 打开时崩溃，导出时关闭了「自动加 (CONT'D)」，需要时可在 Final Draft 里重新打开。 |
| 导出纯文本… | 便于复制、阅读的 TXT | 用文字、空格和换行表达排版，不保留富文本与图片。 |
| 导出 Markdown… | 在支持 Markdown 的工具中整理、阅读 | 用标题、人物强调等表达剧本结构，不保留素材或完整视觉排版。 |
| 导出网页 HTML… | 用浏览器打开的独立剧本文档 | 含文字与样式，不是整个软件工作区，也不含素材卡或改稿库。 |
| 统计 → 导出 CSV | 汇总场景、人物、幕等统计 | 输出统计表，不是完整剧本文字或工程备份。 |

### 创作版 PDF

先切到“写作”，核对图片与声音卡的位置、文字颜色及卡片内容。再选“文件 ▾ → 导出创作版 PDF（原位卡片）…”，选择保存位置，等待完成。导出可能临时切换视图，完成后恢复原视图。

导出需要等排版、字体和图片就绪。如果等待期间修改了正文、切换了工程或视图，这次导出会停止，并提示“请重新导出”，这样不会输出过期内容。

创作版使用适合画布的数字页面，不按 A4 重新排图文；超长画布会在适合的位置分页。如果提示画布过宽或存在无法完整放入一页的图文组合，把远离正文的卡片移近，或缩短过长内容后重试。

### A4 纯文本 PDF

1. 点击“预览”，检查“A4 纯文本打印预览”中的分页、场号、对白和标题页。
2. 需要独立标题页时，同时检查标题页的显示选项与“设置 → 版式 → 标题页独立成页”。
3. 点击预览中的“导出 A4 纯文本”，或用文件菜单的同名 PDF 入口，选择位置并等待完成。

此出口固定为 A4；设置里选择 Letter 不会把“导出 A4 纯文本 PDF”变为 Letter。预览旁的“导出创作版（含卡片）”是另一种出口。**⌘/Ctrl+P 对应 A4 纯文本 PDF。**

### FDX、TXT、Markdown、HTML 与 CSV

从“文件 ▾”选择对应导出项，选择文件名与位置。导出后用接收方会使用的软件重新打开，检查中文、段落类型和版式；这些格式不保留整个工作区，也不能代替 `.zhsp`。

“统计”中可查看字数、页数、预计时长、场景与人物等信息，再点击“导出 CSV”。时长是按设置中的字数速度估算，不是影片实测时长；不同场景共享一页时，各场页数相加也不等于全稿独立页数。

### 备忘、省略与私密改稿记录

各出口的过滤规则不同，交稿前请实际打开导出文件核对：

- **备忘：**创作版 PDF 保留写作画布里的备忘；A4 纯文本 PDF、FDX、Markdown 当前不输出备忘；TXT、HTML 是否包含备忘，取决于“打印「备忘」元素”。
- **省略：**A4 纯文本 PDF 和 FDX 都排除标记省略的正文元素和整场（FDX 里后面的场号保持原编号）；创作版及 TXT、Markdown、HTML 不应当作统一排除省略文字的出口。要彻底移出当前交稿正文，应明确暂存并移出，然后再导出检查。
- **改稿库：**版本、暂存、批注、创作决定、交稿忽略记录与工作台界面不进入以上正式剧本导出。旧稿一旦取回插入正文，就成为当前正文，按所选格式正常导出。
- **辅助场景信息：**卡片简介和修改状态用于组织创作，不会自动追加到正式剧本中。需要观众或读者看到的信息，应写进正文。

## 11. 哪些内容随工程保存

| 内容 | 保存与分享方式 |
| --- | --- |
| 正文、标题页、排版设置、修订标记 | 随 `.zhsp` 保存；不同导出格式只保留各自支持的部分。 |
| 场景归幕、辅助信息、素材卡、图片、关系线和位置 | 随 `.zhsp` 保存；素材是否呈现在交稿文件中取决于出口。 |
| 命名版本、暂存、批注及决定、忽略记录 | 随 `.zhsp` 保存，不进入正式剧本导出。把工程发给别人，也会分享这些改稿资料。 |
| 人物登记、精确别名、作者纠正及人物笔记关联 | 随 `.zhsp` 保存；不进入正式导出，旧版再次保存可能丢失新增人物线信息。 |
| 最近项目、启动偏好、界面外观、写作位置、人物线阅读书签 | 本机使用偏好，不是正式剧本文字。 |
| 撤销历史、尚未确认的窗口草稿 | 不作为工程的永久历史保存。重要结论应确认，重要稿件应保存。 |

若只想发送当前交稿内容，选择相应导出文件并检查；若要交接可继续编辑的全部工作，则发送 `.zhsp`，同时留意其中可能包含的旧稿和内部批注。

## 12. 常见问题

**为什么已经有“恢复点”，名称旁仍有圆点？**

恢复点与工程保存分别工作。圆点表示工程仍有未保存修改，请点击“保存”。

**版本取回按钮不可用，或插入位置不对怎么办？**

先关闭工作台，在正文点入真正想插入其后的段落，再重新打开“改稿”，核对目标提示。工作台使用打开时的位置，不会猜测后来的意图。

**为什么批注找不到原来的几个字？**

原文可能已经变化或被删除。软件保留旧摘录与决定，避免把批注错挂到相同文字；重新选好范围后明确“重新挂接”。

**为什么图片在自由板拖走了，创作 PDF 里还在原处？**

自由板与写作画布各自保存位置。请在“写作”里调整图卡，再导出创作版 PDF。

**为什么故事板里的移动会改变正文，自由板拖动却不会？**

故事板的正文排序与归幕操作移动的是整场；自由板拖动安排的是空间布局。移回“未归幕”又是单独的规则：解除归属，保留正文位置。

**为什么 Enter 没有另起一段？**

若快捷输入候选正展开，第一次 Enter 先接受候选；再按一次才切段。中文输入法确认汉字也应先完成组词。

**为什么 A4 PDF 没有图片或备忘？**

这是当前 A4 纯文本出口的范围。需要正文旁的图卡、声音设计和画布内容时，使用创作版 PDF；不要只更改文件名后缀。

**为什么旧稿、批注没有出现在导出文件？**

它们属于改稿资料，保存在 `.zhsp`。确需进入交稿正文的旧段，应先取回插入；批注或决定中需要写给读者的话，应明确改写进正文。

**如何报告问题？**

在 [GitHub Issues](https://github.com/libingzheng00-eng/guangying-writer/issues) 提供软件版本、系统、复现步骤及脱敏截图。尽量用新建的虚构小剧本复现，不上传真实剧本、私人路径或未公开创作资料。
