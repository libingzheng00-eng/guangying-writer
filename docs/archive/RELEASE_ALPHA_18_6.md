# alpha.18.6 本轮交付核对

日期：2026-09-10。此文件记录本地核对，不代表 GitHub 已推送、合并或发布。

## 范围与隔离

- 故事板：未归幕、归幕落点、折叠/命名/删除幕、多选移动及单次撤销。未归幕只解除归属，保留正文位置；删除幕不删戏。
- 统计：总览、幕/场景比例、人物发言分布、地点/时段、待处理、CSV；保留精确角色改名和撤销。统计使用只读投影，不替换其他界面的公共统计或分页。
- 自由板：可关闭的淡网格、可见卡片与连线过滤、明确连接入口、整场删除确认、无保存尺寸的场景卡提高默认显示高度。已有位置/尺寸、关联素材不迁移。
- 写作周边：普通格式/多选原位工具区，导航不重复场名；目标占比色带不再被样式撑满。页数按内容取宽，使用本机 Snell Roundhand 英式圆手体，统一间距；进度栏高度仍76px、顶栏仍52px，不改编辑器或导出布局。
- 不加入搜索、卡片分组框等新范围；不改现用应用，不读取或修改用户剧本。素材拖入、Tab九类焦点闭环、原位PDF和撤销仍为红线。
