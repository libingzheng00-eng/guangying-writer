# 光影写手 v1.3.0-alpha.18.8

本版仅精简自由板卡片外观，保留 alpha.18.7 的输入性能优化。

## 改动

- 场号放在场景标题左侧，连接和删除改成小图标，悬停提示仍明确说明用途。
- 场景颜色覆盖整张卡片，日间淡色、夜间低亮度；选中外框独立显示。
- 隐藏“缩放”文字和灰底，保留右下角斜线手柄；图片卡去掉重复的“图片”标签。
- 不改正文、Tab、保存格式、PDF、卡片坐标/尺寸和删除撤销逻辑。删除整场仍先确认。

## 下载与安全

- Mac M1/M2/M3/M4 等 Apple Silicon 使用 DMG，打开后将“光影写手”拖到 Applications；ZIP 为同版备用分发形式。
- 更新前保存自己的 `.zhsp`，保留备份并正常退出旧应用。安装包不包含任何用户剧本。
- 仍是 alpha 测试版，仅做 ad-hoc 签名，未经过 Apple 公证；不能保证所有电脑无安全警告运行。遇到系统拦截请保留提示，不关闭系统安全保护。
- 本地 DMG SHA-256：`7182f79b1d18be5ae119aaa7d977fb9560cf839a1d3f2a740ea643436c686a18`。GitHub CI 如重新构建，二进制哈希可能不同，请以对应附件为准。
