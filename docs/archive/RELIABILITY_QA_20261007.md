# 恢复、落盘与写作派生验收记录

日期：2026-10-07。对象是本仓库当前源码构建，manifest 版本仍为 `1.3.0-alpha.18.10`；不是旧安装包，也不是新公开 Release。仅使用空白模板和新建合成稿，没有打开、修改、导出或上传用户剧本。本轮不替换现用应用，不生成公开 DMG。

## 1. 本轮交付范围

- 自动恢复：独立状态反馈、900ms 停笔写入、连续修改最长约30秒更新、关闭同步 flush、恢复/存储失败提示、损坏恢复载荷保护。正常写入只有一个最新快照，不复制图片历史。
- `.zhsp`：同目录独占临时文件、文件 fsync、上一版备份和 rename；同目标排队，校验身份与权限，失败不先截断原稿；目录耐久性警告不误报已提交保存失败。
- 写作派生：复用元素索引、同人物续说投影及 SmartType 目录解析。不重写分页、隐藏测量或字体等待，不改九类 Tab、智能引号或双列跨栏顺序。
- 分层验收与文档：新增源码回归、独立 Electron 合成壳和固定模式 launcher。测试夹具替换先加载新窗口，再销毁旧测试窗口，不能关闭产品 guard 来绕过测试失败。

**备份限制**：成功保存时备份为替换前的工程。若备份替换已成功而最后的工程 rename 失败，当前工程仍保持原样，但备份可能与当前工程同版本；它不是多版本历史库，不保证每次失败还保留更早一版。普通 POSIX mode 可保留，ACL/xattr 不全保留；没有跨进程锁或任意文件系统断电无损承诺。

## 3. 真实 Electron / Chromium（已实跑）

独立 QA `.app` 使用本机已有完整的 Electron 31.7.7 arm64 运行时复制件、独立 bundle ID、临时 userData 和当前 `dist-renderer`。只给此测试副本做 ad-hoc 签名；没有移除隔离属性、改变 macOS 安全设置、Apple 公证或重签用户正式应用。启动成功不代表分发签名已解决。

| 模式 | 已确认 |
| --- | --- |
| editing | 段中 Enter 移动尾文、富文本/BR边界、跨段剪切/粘贴、连续输入与3步撤销、菜单撤销重做；11次Tab和11次Shift+Tab焦点保持。剪贴板事件为内存DataTransfer，不冒充系统测试 |
| input | 300段合成稿连续输入30字完整、焦点不跳；CDP组合提交不残留拼音；同隔离存储/同入口无新seed重建窗口后正文与图片恢复 |
| search | 菜单查找、输入、上下处、大小写、Range高亮、长稿定位、空结果/Esc；正文与恢复数据不变 |

长稿测得25次输入到两个动画帧的中位数 **12.8ms**、最大 **24.2ms**。这是这一台机器和这一组合成样本的结果，不是按键端到端延迟、优化前后对比或所有长稿性能保证。

## 4. macOS 系统剪贴板与实际关闭（已实操）

用户先将剪贴板换成非隐私占位内容。没有读取或备份之前的剪贴板；测试只在独立空白合成窗口输入 `NativeClipboardQA`。

- 真实 ⌘X 使该选中文本消失，⌘V 恢复原文。
- 连续两次 ⌘Z：依次撤销粘贴和剪切；两次 ⇧⌘Z：依次重做剪切和粘贴。
- 真实 ⌘C 复制；明确将光标置于末尾后 ⌘V，文本恰好追加一次；一次 ⌘Z 恢复原文。
- 第一次复制试验的选区未真正收起，所以粘贴只替换同一段，不算成功证据；后续明确光标位置才确认追加。未据此改产品代码。
- 真实关闭按钮触发“继续写作 / 仍然离开”原生提示；选继续写作后文本保留；再次关闭并明确选仍然离开后窗口关闭。

## 5. 实际 PDF（已生成、提取并看图）

`pdf-layout-electron.cjs` 使用合成七场稿，第五场两侧放声音卡与项目内打字机PNG。

- 创作版正文、图片和声音卡的坐标/尺寸与画布误差小于1px；没有素材文末附页，导出未改变原工程与卡片位置。实际PDF为一个自定义长画布页，看图确认第五场旁两张卡保留。
- A4纯文本为2页、约594.96×841.92pt，没有声音或图片卡；看图确认内容正常连续。
- 长对白/长动作8页：250个唯一行标记全部恰好一次。
- 既有双列分页3页：170个唯一左右栏行标记全部恰好一次；不代表双列跨栏选区的新语义被实现。
- 28组短对白3页：分别11/12/5组，人物与对应对白同页。看完三页，无原先强行绑定导致的大片提前空白；最后页尾空白是稿件结束。
- 4,266,798字符的大图HTML通过新PDF通道生成3,226,955字节PDF；实际看图含整张合成噪点图。对照旧data URL重现 `ERR_INVALID_URL`，仅作为旧缺陷对照。
- Poppler渲染部分中文字体报告font type mismatch警告；渲染图中的中文可见。没有据此宣称任意字体/读者软件均无问题。

## 6. 仍未验证的边界

- **真实 macOS 中文输入法候选窗与物理键盘组合过程**：CDP模拟不替代它。也未验收Windows/Linux。
- 当前独立测试副本中，文件打开对话框对临时合成 `.zhsp` 的“打开”按钮保持禁用，即使所有文件筛选也未解除；已取消，没有绕过系统限制。尚未定位为测试壳/环境还是产品问题，不将它写成正式应用缺陷或声称原生文件打开/保存对话框验收通过。文件命令、保存IPC和真实文件系统专项另已通过。
- 刚输入最后两字立即关闭的时序由同步flush专项覆盖；人工原生关闭操作本身未精确卡在900ms内，不能替代该时序证明。
- 原生Finder拖拽手势、任意超大图片工程、硬断电与网络盘并发未覆盖。

因此本轮有源码回归、实际系统剪贴板/关闭证据和实际PDF证据，但不是“所有平台全功能零风险认证”。公开安装版仍应独立构建、隐私检查和发布，不应把这个临时验收壳分发给用户。
