# 光影写手 alpha.18.10：编辑与查找修复

日期：2026-09-20。状态：本地候选；未推送、未公开发布、未覆盖用户现用应用。

## 本次处理

1. 聚焦正文的 DOM 不再拒绝来自模型的变化，回车分段、剪切/粘贴撤销/重做立即显示正确内容；普通输入已一致时不重写 DOM。
2. 富文本和 BR 边界按统一文本偏移切分。回车移动尾部；选区回车替换所选范围，不保留重复尾文。
3. 剪切/粘贴/跨段替换是独立撤销事务，不与前后输入合并。复制不修改历史，字面实体和 emoji 不重复解码；对外复制保留 HTML 富文本，内部粘贴保持既有纯文本策略。
4. 新增“查找正文”：顶栏按钮或 ⌘/Ctrl+F；Enter/Shift+Enter 上下处、点击结果定位、大小写开关、Esc 关闭。查找正文（含备忘/省略段及双列），不搜索素材卡或标题页，不提供替换。高亮不写入正文、不改变工程或导出位置。大量结果只绘制前 2000 处及当前处的高亮，计数和逐处导航仍覆盖全部命中。
