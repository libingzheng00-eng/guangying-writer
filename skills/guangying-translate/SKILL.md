# 光影写手剧本翻译

作者用中文写剧本；你通读全剧、理解人物和故事气质后，逐段翻成日文（ja）或英文（en），
写进 .zhsp 文件里每段的「译文」位置。原文一个字都不改。作者打开文件，点顶栏「双语」，
左边是原文，右边是你的译文。

脚本在本技能的 `scripts/` 目录，用 Node 运行，不需要安装依赖。下面 `$SKILL` 指本技能目录。

## 步骤

1. **确认文件和语言。** 问清楚是哪一个 .zhsp 文件（完整路径）和目标语言（日文 ja / 英文 en），
   请作者先在光影写手里**保存并关掉这个剧本**，避免两边同时改。
   这是作者自己的剧本：只在作者明确要求翻译时读取，只读这一个文件。

2. **取出段落。**
   - 第一次翻译：`node $SKILL/scripts/extract.mjs <剧本.zhsp> --lang ja --out /tmp/worklist.json`
   - 改稿后只翻改过 / 还没翻的：加 `--only-needed`
   结果里有：人物表、每场的场次标题和梗概、已有译名表，以及每段的 `id`、类型、所在场次、说话人、原文和状态
   （`missing` 未译、`stale` 原文改过待复查、`done` 已译）。

3. **通读全剧，写一份翻译说明（先给作者看）。** 读完所有段落再动笔，整理：
   - 故事梗概、时代地域、整体语气（冷峻 / 温情 / 喜剧……）；
   - 每个主要人物的说话方式（年龄、身份、彼此关系、口癖）；
   - **译名表**：人名、地名、专有名词的固定译法（日文人名给出汉字或片假名及读法的选择理由；英文用拼音或作者指定的名字）；
   - 拿不准的地方（双关、方言、文化梗），各给一两个译法备选。
   把译名表和拿不准的地方发给作者确认；作者没空确认时，按你的判断先翻，并在说明里标出来。

4. **逐场翻译，写成译文 JSON。** 格式：
   ```json
   { "items": [ { "id": "段落 id", "text": "译文" } ],
     "glossary": [ { "source": "林舟", "target": "リン・ジョウ", "note": "可选说明" } ],
     "notes": "给作者看的翻译说明：语气、人物说话方式、拿不准的地方" }
   ```
   每段一条，`id` 必须照抄。只翻 `text`；不要合并或拆分段落。长剧本分几批写，每批一个 JSON 文件。

5. **写回文件。** 先试运行再正式写：
   - `node $SKILL/scripts/apply.mjs <剧本.zhsp> <译文.json> --lang ja --dry-run`
   - `node $SKILL/scripts/apply.mjs <剧本.zhsp> <译文.json> --lang ja`
   脚本会在原文件旁边留一份「翻译前备份」，写完后核对原文没有变；如果期间文件被别处保存过，会拒绝写入，重新从第 2 步开始。

6. **告诉作者结果：** 写了多少段、译名表要点、拿不准的地方，以及「打开剧本 → 顶栏『双语』→ 选日文 / 英文」即可对照查看和修改。

## 翻译要求

- **按人物说话。** 对白要像这个人会说的话，不要逐字直译。
- **日文（ja）：**
  - 对白用自然口语，敬语 / タメ口按人物关系和场合决定，前后一致；
  - 动作描写用简洁的现在时（〜する／〜している），像日本剧本的ト書き；
  - 场次标题按日本剧本习惯，例如「〇 候船室（夜）」；括号提示用（ ）；人物名照译名表。
- **英文（en）：**
  - 场次标题用 `INT./EXT. LOCATION - DAY/NIGHT`，全大写；
  - 动作用现在时、短句；人物名照译名表（对白上的人物名用大写）；
  - 括号提示用 (lowercase)。
- **转场、镜头**（切至、淡出、特写……）用目标语言的行业惯用说法。
- 保留原文的换行；粗体、斜体等格式不需要保留（译文是纯文本）。
- 双列对白、备选台词：只翻当前文字，`dual` 字段只是提示，不用处理。

## 不要做的事

- 不改原文、不删段落、不动 .zhsp 里除译文和译名表以外的任何内容（脚本已保证，不要手工编辑文件）。
- 不把剧本内容发到任何外部翻译服务或网站。
- 不读作者没有指定的其他剧本文件。
